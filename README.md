# GTA V — 100% Completion Tracker

A single-file, self-contained progress tracker for the GTAForums "GTA V 100%
Total Completion Strategy Guide" by Jimbatron. 404 tracked tasks across all
5 chapters + Epilogue, with per-character color coding, a search bar, a
"flag for later" system for out-of-order progress, and an overall progress
bar.

Progress is saved locally in your browser (`localStorage`) — it's private to
you and persists between visits on the same device/browser. Nothing is sent
anywhere.
